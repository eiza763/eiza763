## 🚀 Featured Projects

### [AgentLens](https://github.com/eiza763/agentlens) · TypeScript
Agent quality as a first-class observability signal. Instruments an AI agent with
OpenTelemetry, ships traces to SigNoz, then reads those traces back out to grade what
the agent actually did — writing the scores back in as telemetry. Quality becomes
something you can graph, alert on, and block a deploy on.
Built for the **Agents of SigNoz** hackathon (Track 01 — AI & Agent Observability).

### [Recall](https://github.com/eiza763/recall) · TypeScript
Full-stack app with a separate backend and frontend, exploring persistent memory
for AI applications.

### [Doctor Appointment](https://github.com/eiza763/Doctor-Appointment) · JavaScript
Appointment booking system built on the MERN stack.

### [Green Cart](https://github.com/eiza763/Green-Cart-main) · JavaScript
E-commerce storefront with cart and checkout flows.
